# 好時光日誌 Good Times Journal

一個以桌面電腦為主、可離線開啟的 DYL「好時光日誌」網站原型。保留 Week 2 的每日記錄，以及 Week 3 的四色情緒標記、能量拆解與反思。

## 怎麼打開？

直接雙擊 `index.html`，或在瀏覽器中開啟。**不需要安裝 Node.js、Python 或任何套件。** 建議使用最新版 Chrome、Edge、Firefox 或 Safari。

## 目前有哪些功能？

- 每日預設三件事件，可繼續新增，包含事件描述、感受與想法、單選心情 Emoji、0–100 投入滑桿。
- 每日一句話總結、記錄進度、即時自動儲存。
- 週回顧：四象限情緒多選；使用滑鼠選取事件中的文字後，以四色螢光筆標記不同部分。
- **每件事件都會出現在情緒儀錶板**，可以直接以滑鼠拖曳到任意位置；也可用方向鍵微調（Shift + 方向鍵可一次移動更多）。位置會自動保存，切換週次或重新開啟網站仍可保留。
- 三個週回顧問題各有文字輸入框；最下方還有「完成探索後的心得感想」大文字區。每週獨立儲存，包含於備份與分享摘要。
- 週回顧：為個別事件輸入「充電元素」及「耗電元素」；統整常見元素、情緒四象限視覺化。
- 一週摘要可複製（包含已填寫的週回顧回答與心得，不自動分享）。
- 生活日曆檢視、JSON 備份下載及匯入、清空資料、範例資料。

### 重要：投入 ≠ 能量

投入程度是時間、心力、體力等主觀投入的概念；情緒四象限則是「高／低能量 × 高／低愉悅」，**兩者分開儲存**，不會直接由投入分數推算情緒。

## 發布到 GitHub Pages（讓別人開連結）

1. 登入 [github.com](https://github.com/)，新增一個 public repository，例如 `good-times-journal`。
2. 把這個資料夾中的 `index.html`、`styles.css`、`app.js`、`favicon.svg`、`README.md`（和 `.nojekyll`）全部上傳到該 repository 的根目錄並 commit。
3. 開啟 repository 的 **Settings → Pages**。
4. 在 **Build and deployment** 中，選擇 **Deploy from a branch**，將 **Branch** 設定為 `main`，資料夾設為 **/(root)**，按 Save。
5. 部署完成後，網站通常位於 `https://你的GitHub帳號.github.io/good-times-journal/`。

GitHub Pages 是靜態網站代管服務，適合這個不依賴伺服器的原型。它不會提供帳號登入、跨裝置同步或共用資料庫。

## 資料儲存及分享限制（務必閱讀）

**每個人在相同網址上開啟網站，仍是各自在自己的瀏覽器記錄。**

資料保存在 `localStorage`，不是 GitHub，也不會提交到 repository。網站沒有帳號系統、伺服器資料庫或第三方分析追蹤。別人開啟同一個網址，不會看到你的日誌；你也看不到他們的內容。相反地，**切換裝置、改用其他瀏覽器、無痕模式結束、清除網站資料，都可能造成紀錄消失**。定期從「使用指引」下載 JSON 備份；可以在另一部電腦匯入。

GitHub Pages 發布的程式碼是公開可見的。請勿把個人日誌、帳密、API 金鑰等私人資訊直接放進 GitHub repository。

## 關於示範資料

使用指引中的「載入示範資料」會將範例填入**上一週空白日期**，不覆蓋已經有內容的日期；它只是為了展示儀錶板，不是學員資料。

## 技術資訊

純 HTML + CSS + JavaScript；不使用外部 CDN、無需建置流程。所有使用者輸入皆在顯示時做 HTML escape。資料匯入會進行欄位與長度檢查。

## 更新既有 GitHub Pages 網站

如已經上傳過舊版，只要把 `index.html`、`styles.css`、`app.js`（以及其他要更新的檔案）覆蓋到同一個 repository 的根目錄並 commit，GitHub Pages 就會更新網站。原先記錄在同一網址和同一瀏覽器的日誌會沿用；建議更新前先下載 JSON 備份。
