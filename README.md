# Design your life · DYL_1.0

直接用瀏覽器開啟 index.html，不需安裝套件。建議以 Chrome 或 Safari 使用。

## 功能
- 首頁：好時光日誌、奧德賽計劃（三個五年計畫）。
- 保留日誌側邊欄、生活日曆、備份匯入匯出。
- 每日固定三件事、Emoji、投入程度、選填感受、一句話總結。
- 按儲存後顯示三張探索卡：四色文字標記、充電與耗電元素。
- 文字便利貼可拖曳或用方向鍵調整位置；最後按儲存今天所有資料。
- 每週回顧以週一至週日顯示所有事件；點便利貼可查看詳情及回到當日編輯。
- 檸檬色系：#FFD43B、#FFF4A3、#A8C64A、#6E8E23、#355E1B。

## 原型帳號與資料
登入／註冊以本機瀏覽器模擬，可建立帳號、檢查密碼、登出及分開保存各帳號紀錄；亦可不登入試用。帳號密碼至少為 2／6 字元。密碼以隨機 salt 與 PBKDF2 雜湊保存，不保存明文。
這不是正式後端驗證：資料存於 localStorage，登入狀態存於 sessionStorage，不會跨裝置同步。正式研究版本仍須接上後端認證、資料庫及存取權限。測試請勿使用真實常用密碼。
畫面依需求不顯示本機儲存提示。草稿自動保存，探索開啟狀態、標記、元素與便利貼百分比座標一併保存；每日最終儲存另記完成時間。
若瀏覽器阻擋儲存，畫面會提示失敗。可下載 JSON 備份轉移資料。匯入只保留每日前三件事件，請先備份舊檔。

## 來源
以 dyl-good-times-journal-main 為基礎改寫，沿用日誌資料結構、文字選取標記、儀表板拖曳、日曆與備份處理。原始資料夾未修改。

## 本機預覽（可選）
在本資料夾執行：

    python3 -m http.server 8766 --bind 127.0.0.1

然後開啟 http://127.0.0.1:8766 。不同網址與 file 開啟模式的資料各自獨立。

## 奧德賽計劃
從首頁「奧德賽計劃」進入。新增檔案為 odyssey.js、odyssey.css、assets/odyssey-illustration.svg。

- 總覽與 Plan A／B／C；每個計畫獨立儲存。
- 2027–2031 橫向時間軸：新增事件、編輯標題與描述、上傳／更換／移除圖片、換年份、上移／下移與確認刪除。
- 15 件完整事件為目標，圖片選填；不阻擋儲存或匯出。
- 四個 0–100 評估、獨立滿意度、複選與自訂價值觀、三個好奇的問題。
- 未評估為 null，0 分是有效評分。
- IndexedDB 保存整份計畫及圖片，不使用暫時性圖片 URL；沿用目前登入帳號區分資料，訪客另存。
- JSON 備份包含三個計畫、事件順序與圖片，可匯入還原。與好時光日誌的 JSON 分開備份。
- 列印／匯出 PDF：先預覽三個計畫，再選瀏覽器列印及另存 PDF，建議 A4 橫式。列印版依年份依序排列全部內容，不包含操作側欄。
- 手機使用「計畫選單」，時間軸可水平捲動。

原型限制：沒有正式後端、跨裝置同步或多人協作。圖片單張上限 5 MB（PNG／JPG／WebP／GIF）；JSON 匯入上限 100 MB，每個計畫最多匯入 1000 件事件。儲存容量取決於瀏覽器；失敗時會提示下載備份。建議以本機 HTTP 預覽啟動，避免瀏覽器限制 file 開啟模式的儲存。

已人工確認主要編輯、跨計畫資料獨立、圖片重新載入、排序換年、0 分與未評估、JSON 含圖片還原，以及三個計畫列印預覽。依使用者要求停止後續測試；實際 PDF 分頁與手機操作待自行檢視。
